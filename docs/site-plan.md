# 回声主页站点计划

## 目标

为 Echo 建立一个独立、求职导向的个人主页，清晰展示前端基础、AI 应用全栈方向、AI 协作研发方式和真实个人项目。

## 页面结构

1. Hero：姓名、定位、价值主张和主要行动。
2. About：从前端到 AI 应用全栈的成长主线。
3. Engineering：AI 协作研发、应用工程、质量与可信度。
4. LeanMate：瘦搭作为完整产品能力案例。
5. Voya：漫游作为 AI 规划与可信体验案例。
6. Contact：求职方向、邮箱、GitHub 与简历。

## 3D 叙事

宇航员和空间站贯穿页面并随滚动演化。宇航员路径与镜头路径相互独立，GSAP ScrollTrigger 负责把场景状态与 DOM 章节进度绑定：

- Hero / About：宇航员与空间站建立首屏构图，镜头逐步进入飞行路径。
- Engineering / LeanMate：穿越走廊与变化的灯光空间。
- Voya：进入碎片、闪光和蓝色传送门空间。
- Contact：宇航员与多层贴纸构成联系场景，叠加指针动作。

`components/scene/lusionTimeline.ts` 定义归一化时间轴，位置曲线、旋转与背景色按进度采样；GSAP ScrollTrigger 同步滚动和 DOM 文案。骨骼动作可随滚动正反采样，指针交互叠加镜头及角色姿态。减少动态效果时保留完整 DOM 内容，关闭滚动路径与主要指针动画；完整交互和视觉验收仍待补齐。
